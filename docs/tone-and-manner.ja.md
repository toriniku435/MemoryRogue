# トンマナ（トーン＆マナー）

ゲームの見た目・手触り・言葉づかいの決まりごとです。`CLAUDE.md` から読み込まれます（日本語版は [CLAUDE.ja.md](../CLAUDE.ja.md)）。**画面・画像・アニメーション・ラベルはすべてこのドキュメントに従います。** 画像の作り方と、どの画像がどこに刺さっているかは [docs/art.ja.md](art.ja.md) にあります。こちらは「どう作るか」ではなく「どうあるべきか」を書く場所です。

**このドキュメントはユーザーの指摘をもとに保守します。** 見た目・動き・操作・言葉づかいについて指摘を受けたら、コードの変更と**同じ変更の中で**このドキュメントも更新してください。

- 決まりを足すか直す。
- 以前の方針を覆す指摘なら、古い方針を「試してやめたこと」へ移し、理由と日付を書く。

日付の書式は `YYYY-MM-DD` です。最終更新 2026-11-07。

## コンセプト

**サイバー × ポップ × ドット。**

- **世界観:** シンセウェーブの地平線に広がる夜のネオン街と、遠近のついたグリッドの床。
- **たとえ:** プレイヤーはプログラムを組んでいる、という見立てです。
  - プレイヤーが使うものは**コマンド**です(コマンド / Command)。「カード」とは呼びません。見た目は下端に金の接点ピンと切り欠きのあるカートリッジです。
  - 実行リストは**命令メモリ**(番地 `0x00`、`0x01`… のソケットが並ぶ基板)。
  - カードをそこへ積むことは、**命令をメモリへ書き込むこと**。
  - デッキ編集は**プログラムエディタ**です。所持コマンドは`// LIBRARY`、デッキは書いている途中の`// COMMAND DECK`で、デッキの枚数は上限に向かって埋まっていくメモリーチップの列で見せます。
  - ショップは**チップ**を売る**データマーケット**で、画面上は**マーケット / Market**です。「パック」とは呼びません。チップには複数のコマンドが入っていて、買うとそのコマンドをデッキに組み込めるようになります。チップはICチップとして描きます(両側に金のピン、光るダイ)。通貨は**トークン**(`// TOKENS`。金の六角形のデータトークン、価格は`TKN`)です。
  - キャンペーンは**ファーストビルド**で始まります。マップの上で10個のチップをインストールし、プログラムがそこから自分でデッキを書き上げます(`// DOWNLOAD COMPLETE`、ファーストビルド)。
  - ステージの結果は**アクセス**です。勝てば`// ACCESS GRANTED`で戦利品を*復号*し、負ければ`// CONNECTION LOST`のあとに**バックアップブースト**として支援トークンが転送されます。
  - キャンペーンのマップは**サイバー空間**です。ステージは**アドレスを持つ部屋(階層)**で、データバスの配線でつながり、右へ奥へと深く進んでいきます。進むときはプレイヤーが**電子**に分解され、パケットとして配線を飛び、次の部屋で組み上がります。

## 色

暗い地に、ネオンの差し色を平塗りで置きます。値はすべて `ArtSource/palette.py` にあります。

| トークン | 用途 |
| --- | --- |
| `BG_DEEP` / `BG_NAVY` / `BG_PURPLE` / `PANEL` | 背景とパネル(半透明の暗色) |
| `CYAN` | 主役: 縁取り、選択、プレイヤー側、「押せる」の合図 |
| `MAGENTA` | 差し色と**警告**: ダメージの数字、払えないコスト、ポップなずらし影 |
| `YELLOW` | **注目**: 今指しているユニットや候補。警告色のストライプ |
| `LIME` | 回復、HP |
| `INK` | 縁取り(真っ黒ではなく、濃紺に寄せた黒) |
| `TEXT` `#E8FBFF` | 暗い地の上の本文 |

- **文字は暗い地に明るい色で置きます。** 暗い`INK`の文字は、ネオンの塗りの上(カードの名前帯)だけに使います。
- **色が変わる面の上には文字を置きません。** 数字はバーの上ではなく、横に置きます。

## 形

- **角:** パネル・カード・枠は、丸めずに**角を斜めに切り落とします**。
- **主ボタン:** **右に傾いた平行四辺形**です。半透明のシアンの面に、ネオンの縁と白い四隅のブラケット。ラベルは傾きに合わせて*斜体*にします。複数並べるときは、傾きに沿って少しずつずらし、斜めに積みます(タイトルのメニュー)。
- **宝石・バッジ類**(コスト、メモリー、ブロック値)は**六角形**です。
- **ポップの要素:** 太い`INK`の縁取り、ぼかさないずらし影、網点、ステッカーのような小さな図形(三角・ジグザグ・輪)。
- **サイバーの要素:** グリッド、回路の配線、`//`で始まる見出し(`// COMMAND MEMORY`、`// SELECT TARGET`)、警告色のストライプ、グリッチの帯。

## ドット

- **絵はすべてドット絵として書き出します**: 低い解像度でアンチエイリアスなしに描き、最近傍で拡大します。細部は1ドット以上の太さで描いてください。そうしないと消えるか、縞のむらになります。
- **フォント:** 文字はすべて DotGothic16 です。フォールバックのフォントはありません。
  - 太字は使いません。疑似太字をかけると潰れます。
  - マテリアルの Face Dilate を 0.2 にしてあり、1ドット幅の線が縮小しても消えないようにしています。
  - **読める最小サイズは画面上でおよそ 16px です。** それより小さくなる文字は、読めないまま出さずに隠します(0.6倍で表示する実行リストのカードは、名前とイラストだけを見せています)。
- **キャラクター**は 64×64 のドット絵で、コマ送りで動きます。アイドルのループ、コマンドを使ったときの行動、ダメージを受けたときの被弾（のけぞりにグリッチと白飛び）。プレイヤーは**ショートカットのサイバーな女の子**（毛先がシアンの銀髪、ヘッドセット、白いオーバーサイズのジャケット）、敵はコンピューターの悪者を生き物や機械として描きます。全員右向きに描き、敵は左右反転して出します。

## 動き

動きは**デジタルでキビキビ**させ、プレイの邪魔は決してしません。

- **移動**は、動いている間ドットの格子に吸着し(カクカク)、ease-out で止まります。
- **出る・消える:**
  - **ブラウン管のような横一線**から開き、横一線に潰れて消えます。
  - カードは線になって行き先(メモリー、アーカイブ、手札)へ飛んで消えます。実行されたカードは光って膨らんでから、上へ抜けます。
- **グリッチ**(横ぶれ、シアン/マゼンタの残像、明滅、ノイズの帯)は短く出します。止まっている要素に乗せるときは、たまにだけにします(タイトルロゴは数秒おき)。
- **状態効果は付いたことを知らせます。** 付いたときは、名前と値を文字だけで浮かせます(黄色)。無効化で弾かれたときは「ウイルス 無効」を灰色で浮かせます。
- **数字は何によるものかを言います。** ダメージと回復の数字には、原因を小さなタグで下に添えます。コマンド(アタック、システムエラー)か、継続効果(ウイルス、リジェネ)です。反転した回復は反転させた効果の名前も添えます。ログとは別に、数字のすぐそばに出します。
- **攻撃が当たったとき:**
  - ダメージは対象の透明度の点滅で見せ(色は乗せません。絵が濁るため)、破片を散らします。
  - ブロックのバリアは、段階的にひびが入って砕けます。
- **開いているものの中身を入れ替えるときに、出てくる演出をやり直しません。** パネルが開いているなら、中身はすぐに入れ替えます。閉じるのは少し(約0.12秒)待ってからにし、カードからカードへ移るたびにパネルが一瞬閉じないようにします。
- **変更を捨てるときは確かめます。** オプションのキャンセル(と、強化を押しても反映するまで確定しないユニット強化のキャンセル、コマンドビルドのキャンセル)は、何も変えていなければすぐ閉じ、変えていれば同じ確認ウインドウで「変更を破棄しますか？」(破棄する / 戻る)と聞きます。
- **編集を上書き・確定するときも確かめます。** コマンドビルドのおまかせは、選んでいるデッキを置き換える前に、そのデッキを示して毎回確かめます。保存は変更を確定する前に確かめ、何も変えていなければそのまま閉じます。
- **チュートリアルは指し示し、講釈しません。** 短い吹き出しを1つずつ、説明するもののすぐ横に出します。ほかは暗くし、そのものだけを黄色い枠で光らせます。操作を求める手では、その部分だけを触れるようにします。右上からいつでもスキップでき、マップのチュートリアルボタンで見直せます。どちらも先に確かめます。練習の戦闘でスキップしたら、戦闘を終えてマップに戻ります。
- **設定は、残す前に聞いて・見て確かめられます。** オプションでは、スライダーを動かすとその音量で聞こえます(効果音はクリック音を鳴らす)。ただし反映を押すまで残りません。変更してからのキャンセルは先に確かめます。ユーザーデータの削除は必ず確かめ、何が消えるかを言い、マゼンタで示します。
- **チュートリアルを勧めるのは一度だけ。** 一度見たら、新しくストーリーを始めても聞きません。マップのチュートリアルボタンからはいつでも見直せます。
- **ストーリーは通信として届きます。** 会話は画面下のテキストボックス(`// TRANSMISSION`、話し手は黄色)で、ぼかしたマップの上に1文字ずつ打ち出します。1回クリックで全文、もう1回で次へ。ひとりでには進みません。エピソードの始まり(チュートリアルの確認の前)と、ステージに勝ったあと(報酬の前)に流れます。
- **編集も買い物もマップの上で。** コマンドビルドとマーケットは、ユニット強化と同じくマップの上に開くウインドウで、別の画面へは移りません。外側をクリックしても何も起きません。コマンドビルドを閉じるのはキャンセルか保存だけ(誤クリックで編集を捨てないように)、マーケットは閉じるボタンです。買ったものはその場で反映され、ウインドウの後ろでマップのトークンが数え下がります。
- **コマンドはリストの間をドラッグで移せます。** コマンドビルドのすべて表示で、所持からデッキのパネルへ(または逆へ)横に引いて離すと、1回で1個ずつ移ります。落とせる側のパネルはシアンに光り、ポインタが乗ると強く光ります。縦に引き始めたドラッグはリストのスクロールです。入らないとき(デッキの上限)はエラー音とトーストで答えます。
- **あきらめる前には確かめます。** バトルのメニューにはオプションとあきらめる(マゼンタ)があり、あきらめるは確認ウインドウ(あきらめますか？ / あきらめる・戻る)を出し、OKしたときだけ敗北として戦闘を終えます。
- **中断する前には確かめます。** マップのメニュー(右上)には中断とオプションがあります。中断は「中断してタイトルに戻りますか？」(中断する / 戻る)と、進み具合が残ることを伝えてから、タイトルへ戻ります。オプションはバトルやタイトルと同じウインドウです。
- **バトルへ向かう前には確かめます。** 2択の確認ウインドウ(`// CONFIRM`。左にキャンセル、右に主操作のOKと`>>>`の飾り)を出します。ウインドウの外のどこをクリックしてもキャンセルと同じなので、やめるときに狙って押す必要はありません。例外は「やめる」の無い質問で、ストーリー開始時のチュートリアルの確認(見る / 見ない)は外のクリックを受け付けません。うっかり触れて答えてしまわないようにするためです。
- **期待は光で見せ、光は上がるだけです。** レアリティの色はどこでも同じです(ノーマルはシアン、レアはマゼンタ、エピックは金で虹色に揺らぐ)。何かを明かすとき(パックのインストール)は、光を一番下の色から始め、本当の結果まで1段ずつ昇格させ、段が上がるほど派手にします(輪、閃光、さらに揺れと粒)。一番良いものは、明かす直前に一瞬溜めます。一番良いものは最後に明かします。結果が伴わない昇格(見せかけの期待)はしません。
- **長い演出は、どこをクリックしても飛ばせます。**
- **判定は落とさず、デコードして見せます。** リザルトのランクはデジタルに現れます。横一線から開き、文字がスクランブルしながら左から確定し、シアン/マゼンタの残像と走査線が走ります。画面は揺らさず、閃光も控えめです。ランクが良いほど間とデコードが長く、確定したときの輪・回る放射光・(SS以上は)虹色が増えます。悪いランクは静かに落ち着くだけです。スコアを先に数え上げ、飛ばしてもランクが現れる瞬間は飛ばしません。
- **報酬は報酬らしく、負けは助けとして見せます。** 報酬ウインドウでは、カードが横一線から白く光って開き、後ろにレアリティ色の縁とゆっくり回る放射光。続いてトークンがチッチッと数え上がり、上がりきるとアイコンが弾みます(短いファンファーレ付き)。負けても責めません。題はシアン、放射光は緑、電源が入り直すように持ち上がる音で、ショップと再挑戦へ促す文言にします。ボタン(受け取る/再起動)は数え上げが終わってから出し、閉じた後はマップのトークン表示が続きを数え上げます。
- **ウインドウの開き方・閉じ方はゲーム内で統一します。** `Common/Views/UI/WindowTransition`を使い、ウインドウごとに別の動きを作りません。
  - **開く:** 枠が横一線から少しチラつきながら開き、背後のぼかしと暗さが徐々にかかります。
  - **閉じる:** 前置きなしですぐに、枠がシアンに光りながら横一線に潰れ、その線が電子の粒になって散りながら縮んで消えます。ぼかしと暗さはその間(0.25秒ほど)に抜けます。その場でパッと消すことはしません。
  - **くっきりしているのは一番手前のウインドウだけ。** ウインドウの上にウインドウを開くと、後ろのウインドウは画面と一緒にぼかしの下に入ります。開く動きに合わせて徐々にぼけ、閉じる動きに合わせて徐々にくっきり戻るので、ぱっと切り替わることはありません。重ねて開いても、画面のぼかし自体は変わりません。
  - ウインドウの**中身**は、その上に自分の動きを足してかまいません(結果のカードは1枚ずつ届き、閉じるときは逆順に潰れる)。枠・ぼかし・タイミングは常に共通のものを使います。
- **シーンの切り替えで固まる瞬間を見せません。** グリッチの帯で画面を覆い、その下で次のシーンを読み込んで初期化し、帯がグリッチ的に抜けて明けます。待ちが長引くときは、固まった画面ではなく`// LOADING`と進み具合を見せます。切り替え中は入力を受けません。新しい画面で登場の動きをするものは、覆いが明けてから動き出します。
- **経路はページをめくる.** マップは10部屋で1ページです。次の10部屋へ進むとき(チャレンジ)は、プレイヤーがパケットになって飛んでいる間に、経路全体が格子に吸着しながら1ページ分左へ流れます。今のページはいつも真ん中にあり、次のページが端にのぞきます。
- **UIのアニメーションは実時間で進め**、1フレームあたりの上限を付けます。処理落ちやスロー再生で演出が飛ばないようにするためです。

## 操作

プレイヤーの手と目を、遠くまで動かさず、待たせないことを優先します。

- **クリックでカードを使います。** クリックすれば必ず積まれます。対象が1つに決まるならその対象、敵が複数いれば**優先ターゲット**です。カードはカーソルが乗った瞬間に浮くので、バッファを素早くなぞっても遅れません。別の敵に向けられるカードは、カーソルを少し(約0.1秒)止めるとカードの上に対象パネルが開きます(その1回だけ別の敵を狙いたいとき用)。パネルが開いたままカードをクリックしても、優先ターゲットに向けて積みます。
  - **優先ターゲットはバトルフィールドで選びます。** 敵をクリックすると優先ターゲットになり、名前と頭の間に`TARGET`の付いた黄色いカーソルが下向きに出て、名前が黄色になります。最初は一番手前の敵で、その敵が倒れると生きている中で一番手前の敵へ移り、敵が残り1体のときは出しません。
  - **タッチではホバーが無いので、カードは2回タップで使います。** 1回目で浮かせて詳細を出し(別の敵に向けられるカードなら対象パネルも開く)、もう一度タップすると使います。何も無い所をタップすると下ろします。
  - **タッチでは、タップで開いた説明は、ほかのコマンドや状態効果をタップするまで出したままにします。** コマンドを使っても、何も無い所をタップしても閉じません。実行ボタンを押したときだけは閉じ、実行の結果を隠しません。一度に開くのは1つだけです。実行リストのコマンドも同じで、1回目のタップで説明と並べ替えの矢印を出し、2回目でバッファに戻します。
  - **対象パネルはカーソルを合わせると開きます。** カードのすぐ上に出し、選べる敵が複数いるときだけです。
  - **離れると選択は外れます:** カーソルがカードからもパネルからも離れると(隙間を渡る短い猶予のあと)選択を外します。何も無い所のクリックでも取り消します。
- **選ぶ必要がある代償は、その場で選びます。** ガベージコレクションは対象を選んだ直後に、パージするバッファを聞きます。選んだものにはマゼンタの`PURGE`が付き、カードの上の小さな`// SELECT PURGE`パネルが数を数えて決定を受け付け、何も無い所のクリックで取り消せます。選んでいる間は実行ボタンが「決定」になり、同じように決定できます。いつもターンを終える場所のまま手を動かさずに済みます。
- **敵の次の行動は前もって見せます。** 敵ごとにHPバーの下へ、次の敵のターンの予定を命令メモリーの行(`0x00 [絵] 名前`)で並べます。行を指すとそのコマンドの詳細が出ます。停止で行わない分は暗くします。敵の下の2つの一覧には見出し(`// 次の行動`、`// 状態効果`)を付け、予定を掛かっている効果と取り違えないようにします。状態効果は名前だけを出し、指している間だけ説明を行の真上の吹き出しで開きます。確率で割り込むもの(グリッチ)は見せません。それが驚きになります。
- **次の相手は接続する前に分かります。** マップの**敵詳細 / Enemy Info**ボタンでウインドウ(`// TARGET SCAN`)を開きます。左に次のレイヤーの敵をアイドルアニメ付きで並べ、クリックで選ぶと(黄色のカーソルが指し、枠が光る)右に詳細を出します。HP、毎ターンの行動回数、無効化、短い特徴、使うコマンドをその効果の説明まで。どの文も切らずに全部見せます。
- **ログは原因の名前で書きます。** 継続効果によるダメージや回復は「継続効果で」ではなく「ウイルスで4ダメージ」のように、どの効果かを書きます。
- **対象はカードのすぐそばで選びます**: 選んだカードの真上に、小さな対象の候補一覧が開きます。バトルフィールドのユニットを直接クリックしても選べます。
- **指すと強調されます:**
  - 対象の候補や、積んだカードを指すと、それが作用するユニットが黄色で強調されます。
  - どのカードを指しても、上部の中央の空いている所に詳細が大きく出ます。
- **上限はカードに印を付けます。** バトルの外では、デッキに1枚しか入れられないコマンドの右上の角に、その数(1)を書いた黄色い丸のバッジが付きます(デッキ編集、マーケット、報酬・結果のウインドウ)。カードを大きく見せるときは、絵の上の黄色い札に「デッキに1個まで」とも書きます。バトル中は出しません。デッキを組むための情報だからです。
- **使えないことは、試す前に見えるようにします。**
  - 使えないカードはグレーアウトし、理由がメモリーならコストをマゼンタにします。
  - 指すと浮きますが、何も開きません。
  - クリックすると、理由をトーストで伝えます。
  - 戦闘の外では、同じ決まりを色で見せます。デッキの個数はちょうど必要な数でない間(足りなくても超えていても)マゼンタ(その間は保存できない。編集中に超えるのはかまわない)、パックの価格は1パックも買えないトークンならマゼンタです。
- **画面の何も無い所を、壊れたように見せません。** バッファが空のときも、ただの空き地にはしません。手札の場所に`// BUFFER EMPTY`と、理由(バッファロック、または読み込めるコマンドが無い)と、どうすればよいか(実行を押してターンを終了)を出します。
- **スクロールできる一覧は、そうと分かるようにします。** カードや行がスクロールする一覧(コマンドビルド、コマンドとエネミーのコレクション、バトルログ)には、右に細いシアンのスクロールバーを出し、全部収まるときは隠します。
- **何が起きたかをいつでも読めるようにします。** 行動の処理中は上部中央にログ(`// EXECUTION LOG`)を開き、プレイヤーの番に戻ったら閉じます。**ログ**ボタンで戦闘全体のログ(`// BATTLE LOG`)をいつでも開けます。味方の行動はシアン、敵はマゼンタ、ターンの区切りは黄色で、各行にはその行のユニットの顔を付けます。状態効果は、その下の行に数値入りで説明を添えます(「2ターンの間、回復がダメージになる」)。行動と行動の間は追える程度に空け、その速さは戦闘速度の設定で変わります。
- **見てよい山は開けます。** アーカイブかパージをクリックすると、中のコマンドの一覧(コマンドコレクションと同じ一覧と拡大表示)が開き、戦闘は止まりません。コマンドデッキは開けないので、引く順は分かりません。
- **フィードバックで操作を止めません:**
  - トーストは画面上部に滑り込んで勝手に消え、入力も受けません。
  - 通知のために画面をぼかしたり暗くしたりしません。
  - カーソルを合わせただけではトーストを出しません。
- **プレイヤーが見たい結果は、トーストではなくウインドウで見せます。** 購入結果は出たカードそのものを並べます。こうしたウインドウはモーダルで、背後をぼかし(少し暗くもし)、ボタンで閉じます。読む価値のある結果だけに使い、通知はトーストのままにします。
- **操作の大きさは、その機能の重さに合わせます。** 補助の操作(バトルのログボタン)は、隣の主操作より小さく描きます。
- **主操作**(実行)は一番大きく目立つ操作で、カードゲームで「ターン終了」がある右下に置きます。カーソルを合わせたときと押したときに波紋が出ます。 マップでの主操作は**接続開始 / Connect**(ステージを始める)で、両隣のボタンより大きく(1.2倍)描きます。

## 音

チップチューンとシンセウェーブの中間です。矩形波と三角波のリード、アルペジオ、ノイズのドラム(チップ)を、デチューンしたノコギリ波のパッド、ローパス、エコー(シンセ)の上に乗せます。詳細とどこで鳴らしているかは [docs/sound.ja.md](sound.ja.md)。

- **操作にはすべて、短く応えます。** ホバーはごく小さなチック、クリックは短い2音のブリップです。多くの効果音は0.2秒以下で、素早く操作しても音が重なって団子になりません。同じ効果音は0.04秒以内には鳴らし直しません。
- **音の向きに意味を持たせます。** 確定は上がる(短いアルペジオ)、取り消しは下がる、エラーは低く濁ったビットクラッシュの2連です。押せないボタンを押しても黙らず、エラーで応えます。
- **開封は盛り上げていきます。** チップのインストールは、読み込みの間に低いうなりが「ぐぐーっ」と上がって溜まり、光の色が上がるたびに明るい音が鳴ります(エピックはより大きく、きらめき付き)。コマンドはめくるたびに、ノイズだけの短いシャカッという擦れる音がします。音程のあるブリップは入れません(30枚めくると「ピピピ」と続いてしまうため)。
- **報酬は報酬らしい音にします。** 勝ちは矩形波で上がりきる短いファンファーレにきらめき、負けはやわらかく持ち上がるうねりと和音(励ます音。警告にはしない)、トークンの数え上げはごく短い高いブリップです。リザルトのランクは、ノイズの断片が刻まれて最後にカチッと留まるグリッチ音でデコードされます(ドスンという重い音にはしない)。
- **音も見立てに沿わせます。** カードを積むのはデータのブリップが流れ込んで最後にカチッと留まる音(メモリーへの書き込み)、戻すのは下へすべる音、実行は落ちていくザップです。敵の行動は濁って下がるブズッという音、被弾は短い打撃音、回復はやわらかく上がるチャイム、ウイルスやワームの継続ダメージはぐずぐず泡立つビットクラッシュの音です。自分の操作だけでなく、相手の行動や継続効果もすべて音で分かるようにします。ウインドウは上へ抜けるうねりときらめきで開き、潰れて電子にパチパチと散る音で閉じます。シーン切り替えはグリッチの音です。
- **画面ごとにループの BGM を持ち**、シーンが変わるとクロスフェードします(同じ曲なら途切れず続きます)。タイトルは夢っぽく、マップは探索、バトルは疾走感と高揚感(ループのたびにトランス寄りのビルドアップからサビへ上がる。**長調**にする — 短調のバトル曲は暗すぎた。ドラムは伴奏にとどめ、大げさにしない)、デッキ編集は落ち着いた作業、ショップは弾む感じです。

## レイアウト

- **階層:** 上にバトルフィールド、中央に実行リスト、下に手札。
- **近接:** 使う元手は使う物のそば(メモリー残量は手札の横、マップのトークンはそれを使う2つの操作、マーケットとユニット強化の上)、主操作はターンを終える場所のそばに置きます。
- **一貫性:** カードゲームの定番に合わせます(山札は左下、捨て札は右下、コストはカードの左上)。
- **ウインドウのボタンは、下に1列で中央にまとめます。** どのウインドウでも同じで、読む順に並べます(主操作は最後、右端)。左右の隅に振り分けません。
- **状態を変えるボタンは、その状態の表示の場所に置きます。** コマンドビルドのアクティブにするは、下の段ではなく、デッキの見出しの横のアクティブの札の場所に出します(アクティブなら札、そうでなければボタン)。
- **描画順:** 浮かせたカードや選んだカードが、ほかのパネルの下に潜らないようにします。手札が重なるときは左から順に重ね(右のカードが左のカードの上)、選択中のカードはいつも最前面にします。
- **どの画面の形でも成り立たせます。** 1920×1080(16:9)が基準で、16:10と21:9でも、引き伸ばしや見切れではなく意図した見え方にします。画面が広い分は、世界(背景)がより広く見え、HUDは端に寄ります。バトルフィールドと手札は中央のままです。スマホでは、HUDはセーフエリアの内側に収め、ノッチや角の丸みがボタンを隠さないようにします。組み方は`CLAUDE.ja.md`の「uGUI の組み方」にあります。
